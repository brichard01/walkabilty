# Walkability – Gaze × Scene (Option A)

This repo predicts segment-level walkability from eye-tracking + semantic classes, with interpretable models and a small Streamlit demo.

## How to run (later)
1) `python src/01_build_features.py`
2) `python src/02_train_models.py`
3) `python src/03_explain_shap.py`
4) `streamlit run src/app_streamlit.py`
